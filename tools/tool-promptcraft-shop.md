# promptcraft.shop - free AI video prompt library (via @elaria.labs)

Source: https://promptcraft.shop

Found: 2026-11-08 via @elaria.labs bio ("Free workflows + my Claude skills").

Elaria Vance's prompt library: the exact prompts behind her AI videos (cinematic scenes, effects, UGC, trends). Each prompt page has the full text (not a teaser), the reference images used, and the tool it was made in (ImagineArt, OpenArt, Creatify, Figma Weave, Vosu). Copy-paste workflow: copy the prompt, check the references, run it in the named tool.

Her DM-gated per-reel prompts (e.g. the Seedance 2.0 freeze effect) follow this same format; the hub lists the fresh ones.
